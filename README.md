# Student Record Management System

A Python-based Student Record Management System that uses CSV files to store and manage student information.

## About the Project

This project was developed to practice Python CSV file handling, dictionaries, lists, functions, loops, and error handling.

It allows users to manage student records through a menu-driven program.

## Features

- Add new student records
- View all student records
- Search for a student using Student ID
- Update existing student information
- Delete student records
- Calculate average marks
- Find the student with the highest marks
- Store student information in a CSV file

## Technologies Used

- Python
- CSV module
- Lists and Dictionaries
- File Handling
- Functions
- Exception Handling

## CSV File Structure

The student records are stored with the following columns:

| Student ID | Name | Age | Course | Marks |
|---|---|---|---|---|

*The example above is sample data, not real student information.*

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the Python file:

```bash
python student_record_manager.py
```
